# AGENTS.md

BridgeNode TypeScript SDK (`@bridgenode/llm`). AI inference for AI agents — no API keys, pay per request with Solana USDC via x402.

## Commands

- `npm install` — install deps
- `npm run build` — build (tsup → dist/: index.js ESM + index.cjs CJS + .d.ts)
- `npm test` — run tests (node --test with tsx)
- `npm run typecheck` — TypeScript check (tsc --noEmit)

## Structure

- `src/` — source (entry: `src/index.ts`)
- `tests/` — tests
- `dist/` — build output (GENERATED — never edit by hand)
- `skills/bridgenode/SKILL.md` — agent skill (agentskills.io format)

## Conventions

- TypeScript strict; ESM-first (package `type: module`), but dual build emits CJS too
- Follow existing patterns in `src/client.ts`
- Keep public exports in `src/index.ts` — it's the package API surface

## Rules

- ✅ Always: run `npm run build` + `npm test` + `npm run typecheck` before committing
- ✅ Add tests for new behavior in `tests/`
- 🚫 Never: commit `.env` or any secrets
- 🚫 Never: edit files in `dist/` (regenerated by build)
- 🚫 Never: modify `package-lock.json` by hand — use `npm install`
- 🚫 Don't change version in `package.json` manually for feature PRs (release process handles it)
